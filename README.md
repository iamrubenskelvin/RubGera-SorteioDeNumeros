# 🎲 RubGera - Gerador de Números Aleatórios

Projeto desenvolvido com HTML, CSS e JavaScript para realizar sorteios de números aleatórios de forma simples, moderna e responsiva.

## 🚀 Funcionalidades

* Sorteio de números aleatórios
* Validação de números negativos
* Validação de intervalo inválido
* Layout responsivo
* Design moderno com tema neon roxo
* Efeitos visuais e animações
* Inputs personalizados
* Compatível com dispositivos móveis

---

## 🖥️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
